\fancychapter{Searched Patterns}
\label{app:patterns}

This appendix lists every name the data-flow analysis of Chapter~\ref{sec:toolkit} searches for. Class and method names are matched on the last part of a call, so \texttt{Chroma} matches both \texttt{Chroma(...)} and \texttt{new Chroma(...)}; qualified names are matched after import aliases are resolved, so \texttt{import streamlit as st; st.chat\_input()} matches \texttt{streamlit.chat\_input}. Generic method names count only on a recognized object (Section~\ref{sec:df-recognition}).
